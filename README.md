# WuzzApp

WuzzApp lets Tasker react to WhatsApp activity (messages, statuses, typing and more) and trigger actions on your phone in real time.

Built on [WuzAPI](https://github.com/asternic/wuzapi).

## Disclaimer

This project is **not affiliated with WhatsApp**. Use it responsibly and at your own risk — you are solely responsible for how you use it and any consequences that may follow, including account restrictions or bans.

## Features

- **Real-time alerts:** status posts/deletes, read receipts, typing, and more, configurable per event
- **Contacts:** profile picture sync, number lookup
- **Messaging:** send text, images and locations from Tasker
- **Automation:** cards (Flash, Notify, FAO, Run Task, Say, Vibrate and more) with tap/hold/swipe interactions and conditions (sender, chat/group, time, days, app)
- **Updates:** via [Updater](https://github.com/WhirlWolf/Updater)

See the [User Guide](docs/user-guide.md) for details on every feature.
